***Название:*** Сайт с мини-играми <hr>
***Описание сайта:*** Одностраничный сайт для демонстрации и запуска мини-игр. Основная задача — создание удобного и интерактивного интерфейса, который позволит пользователям легко находить и запускать игры. <hr>
***Особенности сайта:*** 
1. **Валидный HTML-код:** Соответствует стандартам HTML5, использует семантические теги и методологию БЭМ для именования классов.
2. **Точная верстка:** Выполнена по принципу pixel perfect, обеспечивая точное соответствие макету.
3. **Анимации и эффекты:** Реализованы все анимации и эффекты наведения, как указано в макете.
4. **Адаптивность:** Сайт корректно отображается на мобильных устройствах, планшетах и десктопах.
5. **Интерактивные элементы:** Удобные кнопки и карточки для запуска игр; взаимодействие с пользователем через стандартные окна.
6. **Отсутствие ошибок:** Все игры функционируют без сбоев, консоль не содержит ошибок. <hr>

***Использованные технологии:***
1. HTML5, CSS3 (Flexbox, Grid);
2. JavaScript;
3. Git и GitHub для контроля версий.
